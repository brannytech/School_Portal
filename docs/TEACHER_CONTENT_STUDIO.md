# Lesson Studio

Updated 23 October 2026 (Africa/Lagos).

The studio now uses a Word-style ribbon above a white lesson page. There is no permanent setup panel or question sidebar. Open **Teaching workspace → Open Content Studio** (administrators can also open it from School management).

## Start writing

For an empty week, click **Create a lesson**, then write directly on the page. For an empty subtopic, click **Click here to start writing**. Enter the lesson title at the top of the page. Existing content appears in document order; click an item or its small label to edit it.

Use **Home** for text styles, bold, italic, underline, subscript, superscript, lists and alignment. Select text on the page, then choose a formatting tool. **Text** continues the selected text area or adds a new one. Undo and redo work from the ribbon; the selected-item controls move, duplicate or delete the current item.

## Insert teaching content

Open **Insert** for text, equations, graphs, tables, video and links. The additional-item selector includes objectives, worked examples, headings, summaries, experiments and other supported lesson items. New video items need your own YouTube link.

Equations support visual MathLive entry, a mathematical keyboard, fraction/matrix templates and optional LaTeX source. Graphs use labelled coefficient, coordinate and chart-row fields; advanced expressions remain optional. Click an existing item to change its settings. Use **Saved items** to insert a reusable private item; **Reuse this block** below the selected item's editor saves it as a template.

## Choose the week and subtopic

Open **File** to choose a week, press **Load week**, set the weekly topic, select or add a subtopic, and set estimated minutes. **Start blank template** creates an empty private draft for the selected week; it can be undone. Students continue seeing the existing publication until you publish changes.

File also contains version history and **Reload latest**. Historical publications can be compared and restored as a new private draft, then published separately. Existing assignments and attempts are retained.

## Add questions

Open **Questions**, then expand **Subtopic practice** or **End-of-week quiz**. Add a question, choose its answer type, supply the correct answer and write feedback. Multiple choice uses one option per line and a correct-answer selector. Practice belongs to the selected subtopic; the weekly quiz covers the whole week. Panels retain their open state while editing.

## Save and publish

Edits autosave to a private server draft. The bottom status bar shows progress and errors; **Save draft** also saves explicitly. **Preview** shows the lesson and questions at phone, tablet or desktop widths without exposing private question answers or feedback.

Use **Review → Check before publishing** for a checklist. **Go to this item** opens the relevant toolkit and focuses the missing field. Review also contains **Let students open this week when I publish**. Leave it unchecked to publish while keeping the week locked. Press **Publish** when ready; existing daily, term and enrolment rules still apply.

Offline edits remain in memory while the editor is open and retry after reconnection. Refreshing or closing without a successful save can lose unsaved changes. Conflicts retain local work and stop saving; preserve any edits you need before using **File → Reload latest**. This is not live multi-author editing or offline course storage.

Assignments and official examination/result workflows remain in their existing screens. Advanced question authoring remains Phase 4. See the [interactive mathematics guide](INTERACTIVE_MATHEMATICS.md) and [known limitations](KNOWN_LIMITATIONS.md) for supported scope. Browser viewport checks do not replace physical-phone and nontechnical-teacher trials.
